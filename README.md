# Symbia Labs Homebrew tap

```sh
brew install symbia-labs/tap/symbia
```

| Cask | What it installs |
| --- | --- |
| `symbia` | [Symbia](https://github.com/Symbia-Labs/symbia): a signed, hash-chained ledger of AI agent work, served over MCP. macOS on Apple silicon. A cask, so the signed and notarized release binary installs as is, with no Command Line Tools needed. |
